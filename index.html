15 req/s

where it started

Gemma 4 31B answered telecom questions well and served 15 requests a second. Too slow and too large for a platform taking 500K requests a day.

96%+

of teacher accuracy kept

Distillation: train a 4B student, Gemma 4 E4B, to reproduce the teacher's answers. An LLM judge grades it on 135,000+ QA pairs before any release.

88%

less GPU memory

INT4 AWQ: store weights in 4 bits, with scales chosen from real activations so accuracy holds. With the smaller student, VRAM drops 88%.

0 repeats

of the shared prompt

Prefix caching: the attention state for the common system prompt is computed once and reused, so each request pays only for its new tokens.

110 req/s

where it ended

vLLM batches requests continuously on the GPU. Throughput went from 15 to 110 requests a second.
